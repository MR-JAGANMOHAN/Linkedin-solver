# LinkedIn Games Auto Solver

This project automatically solves LinkedIn games daily using GitHub Actions.

## Setup

1. Upload this repository to GitHub
2. Open your repository
3. Go to:

Settings → Secrets and variables → Actions

4. Add these secrets:

- LINKEDIN_EMAIL
- LINKEDIN_PASSWORD

5. Go to:
Actions tab → Enable workflows

Done.

The workflow runs daily automatically.

## Manual Run

Actions → LinkedIn Games Solver → Run workflow

## Important

- Uses very low GitHub minutes
- Stops automatically after solving
- Safe for GitHub free plan
